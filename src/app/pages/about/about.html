什麼是網絡科學

網絡是由節點和節點間的關聯所構成的集合。它可以描述實體的結構，如各台電腦經由電纜關聯起來的網際網路；它也可以描述抽象的系統，如人際網絡，其中的關聯雖然看不見，但是可以藉由問卷、社交網站互動紀錄等推估出來。像化學環繞著研究化合物的特性一樣，網絡科學希望理解網絡的特性，如一個網絡是否在統計上特別、是否存在社群結構等，或發生在網絡上的動態現象，如謠言如何傳播、為什麼會形成「同溫層」等等。

本站的「網路」與「網絡」都指網絡科學（network science）意義下的網絡；收錄的資料包含圖、超圖、單純複形、排名與成對比較等關聯資料，只要它在臺灣蒐集、描述臺灣的人事物，或由臺灣的機構或研究者發布。

下架與更正

任何被資料集或課程紀錄提到的人，以及任何權利人，都可以請本站更正或下架內容：

  1. 寄信到 {{ site.contactEmail }}，說明頁面網址、需要更正或下架的內容與理由。也可以使用資料需求表或 GitHub，但與個資有關的事請寄信，因為 GitHub 是公開的。
  2. 我們會在 7 天內回覆確認收到。
  3. 與個人資料有關、且有合理依據的請求，本站會在 3 天內暫停相關檔案的下載：刪除儲存的檔案、清除快取、在 API 標示該版本暫停下載，並請典藏單位限制已寄存的副本。
  4. 本站會在 30 天內作出決定；需要更多時間時，會通知你並延長一次，最多再 30 天。
  5. 下架的資料集或版本會留下「墓碑」頁：保留識別碼、名稱、下架日期與原因，但不再提供檔案。

課程教師請求移除姓名時，課程仍會列出，教師欄改為「未列出」。來源網站撤下本站轉載的資料時，本站也會跟著撤下。

隱私權聲明

本站由個人維護，依個人資料保護法處理以下個人資料：

  • 資料需求與來信：你在需求表或來信中留下的電子郵件與內容，只用來回覆你，不會公開；需求表由 Google 表單處理。GitHub 上的議題是公開的，依 GitHub 的條款處理。
  • 網站存取紀錄：本站預計使用的 CloudFront 方案不提供存取紀錄。若日後改用提供紀錄的方案，紀錄最多保存 90 天，只用於維運與彙總分析搜尋需求（例如哪些資料常被找卻找不到），並會先更新本聲明。本站不使用第三方分析或廣告追蹤。
  • 研究者紀錄：為了取得轉載授權、並在資料集頁面致謝，本站會聯絡蒐集資料的研究者；聯絡方式、聯絡紀錄與同意紀錄保存在一個不公開的 GitHub 儲存庫（伺服器位於美國），不放在本站或任何公開的地方。只有同意公開致謝的人，才會出現在資料集頁面，且只顯示他同意的欄位。

保存期間：未獲回覆的聯絡方式，自最後一次聯絡起保存 24 個月；同意與授權的證明，在相關資料公開期間及其後 5 年內保存。

你可以依個人資料保護法第 3 條，請求查詢或閱覽、製給複製本、補充或更正、停止蒐集處理或利用，以及刪除你的個人資料：請寄信到 {{ site.contactEmail }}。查詢、閱覽與複製本的請求於 15 日內回覆；更正、停止與刪除的請求於 30 日內回覆，必要時可延長一次並通知你。

網站沿革

  • 2016 年起：以「台灣網絡科學教育」為名，介紹網絡科學，並收集和台灣有關的網絡資料與課程資料。
  • 2018 年：在成功大學統計系《資料科學導論》課程介紹網絡科學（課程封存頁）。
  • 2019 年：整理的電腦工具清單刊載於 PLOS《複雜》頻道；這份清單現在由 GitHub 上的 Network-Code-Repository 維護。
  • 2026 年：改版為搜尋台灣網絡資料與課程的網站，並提供給程式與 AI 代理使用的 API。
